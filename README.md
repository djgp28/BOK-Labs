# bok-labs.com

The BOK Labs landing page: one static page (`index.html` + `site.js`) built on the
[scroll-craft](https://github.com/nateherkai/scroll-craft) engine (`engine/`, unmodified),
served by GitHub Pages from the root of `main`.

Start with `scrollcraft/builds/bok-labs/HANDOFF.md`: page map, mechanics, how to run and
verify locally, deploy procedure, working rules and the full change history.
`BRIEF.md` and `REPORT.md` in the same folder hold the original brief and build report.

Local preview: `node <scroll-craft>/scripts/serve.mjs --root . --port 4500`.
